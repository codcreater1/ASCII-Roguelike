ASCII Roguelike

A simple, single-file ASCII roguelike game written in C++! Navigate your character, avoid enemies, and collect items to increase your score. Perfect for demonstrating C++ skills and having a bit of fun in the terminal.

Features

Single-file main.cpp – clone and run immediately

Playable in the terminal (Windows only for _getch())

Player (@) moves with WASD, quit with Q

Enemy (E) chases the player

Collectable items (*) increase your score

Score increases as you survive longer

How to Play

Clone the repository:

git clone https://github.com/codcreater1/ascii-roguelike.git


Compile the code (Windows):

g++ main.cpp -o roguelike.exe


Run the game:

roguelike.exe


Move with W, A, S, D

Avoid the enemy and collect items

Press Q to quit
